# Migrating from Rheo 0.1 to 0.2

## Supervision

```elixir
# 0.1
{Rheo, url: url, name: Rheo.Mongo, supervisor_name: Rheo}

# 0.2
{Rheo, name: MyRheo, backend: {Rheo.Backend.Mongo, url: url}}
# or shorthand (instance name Rheo, handle Rheo.Mongo):
{Rheo, url: url}
```

Pass `rheo: MyRheo` on APIs and consumers when not using the default instance.

## Consumer

```elixir
# 0.1 — poll GenServer; concurrency ignored
{MyApp.RiskConsumer, name: MyApp.RiskConsumer, max_demand: 10}

# 0.2 — starts Rheo.Group with real concurrency
{MyApp.RiskConsumer, rheo: MyRheo, concurrency: 8, max_demand: 100}
```

`:name` now names the consumer **bridge** process (optional). Group identity is
`{rheo, stream, group}`.

## Query

```elixir
# 0.1
Rheo.query(stream, type: "x", sort: %{"sequence" => -1})

# 0.2
Rheo.query(stream, type: "x", order_by: [sequence: :desc])
# or
Rheo.query(%Rheo.Query{stream: stream, where: [type: "x"], order_by: [sequence: :desc]})
```

## Event decoding

```elixir
# 0.1
Rheo.Event.from_doc(mongo_doc)

# 0.2
Rheo.Backend.Mongo.Codec.event_from_doc(mongo_doc)
```

## Persistence errors

Handler `{:ack, state}` is incomplete until `Rheo.ack/2` succeeds. Groups emit
`[:rheo, :ack, :error]` (and similar) and will not treat a failed ACK as durable
success.

## Lease renewal

Long handlers no longer need manual renewal; `Rheo.Group` renews inflight leases
at approximately half `lease_ms`. Low-level API: `Rheo.renew/2`.
