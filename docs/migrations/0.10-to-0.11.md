# Migrating from 0.10 to 0.11

v0.11.0 is **additive**. Consumer / Event / Query semantics and settle paths are
unchanged. The release adds `Rheo.Backend.Mnesia` — a durable ETS-shaped store
on OTP `:mnesia` (`disc_copies`, single-node).

See [ADR 028](https://hexdocs.pm/rheo/028-mnesia-backend.html).

## Summary

| Area | Change |
|---|---|
| Backend | `Rheo.Backend.Mnesia` (`durable: true`, `distributed: false`) |
| Package | Core OTP — no Hex optional dep |
| Ops | Same inspect APIs as other shipping backends |
| Breaking | None intended for v0.10 hosts |

## Start

```elixir
{Rheo, name: MyRheo, backend: {Rheo.Backend.Mnesia, dir: "/var/lib/rheo/mnesia"}}
```

## Multi-node

v0.11 is single-node. For several BEAM nodes fetching the same group, keep using
Redis or PostgreSQL. See
[Building your own backend](https://hexdocs.pm/rheo/building-your-own-backend.html#multi-node-several-beam-nodes).

## If you stay on 0.10 APIs only

No code changes. Mnesia is opt-in via `backend:`.
