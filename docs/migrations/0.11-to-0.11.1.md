# Migrating from 0.11.0 to 0.11.1

v0.11.1 is a **correctness** patch. Pre-1.0 callers can see three behavior
changes.

See the [changelog](https://hexdocs.pm/rheo/changelog.html#0111---2026-09-20).

## Summary

| Area | Change |
|---|---|
| Pagination | `query_page/2` `next_cursor` is `%{partition => after_sequence}` |
| Fetch | `fetch(missing_stream, group)` returns `:stream_not_found` |
| Capabilities | ETS/Mnesia `atomic_compare_and_set: false` |

## Composite page cursor

Pass the map returned by `page.next_cursor` back as `cursor:`. A legacy
`%{after_sequence: n}` cursor is still accepted as a global lower bound.

```elixir
{:ok, page} = Rheo.query_page("orders", limit: 100)
{:ok, page2} = Rheo.query_page("orders", limit: 100, cursor: page.next_cursor)
```

Integer keys are canonical; string keys are accepted when applying a cursor.

## Stream vs group lookup

`fetch/3`, and the other stream+group inspect calls on ETS/Mnesia, now look up
the **stream first**. A missing stream is `:stream_not_found` even if the group
name is also absent.

## Compare-and-set flag

ETS and Mnesia no longer claim `atomic_compare_and_set: true`. Mnesia
`dirty_write` to `disc_copies` is not crash-durable the way
`:mnesia.sync_transaction` is. The contract suite does not gate on this flag.

## Groups and the `:rheo` application

Local Groups register in `Rheo.Registry` (`{:via, Registry, {Rheo.Registry, {rheo, stream, group}}}`).
The `:rheo` application must be started (normal Mix / `Application.ensure_all_started(:rheo)`).
Look up a Group with `GenServer.whereis/1`, not `Process.whereis/1`.
